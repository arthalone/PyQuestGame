# PyQuest 🐍

**🇧🇷 Aprenda Python jogando.** · **🇺🇸 Learn Python by playing.**

---

## 🇧🇷 Português

**PyQuest** transforma o início do aprendizado de Python num jogo. Você lê lições curtas, testa exemplos, responde quizzes e resolve desafios de código, que são corrigidos na hora. Ao final de cada capítulo, enfrenta um chefão para liberar o próximo.

### O que tem dentro
- 5 capítulos: primeiros passos, variáveis e strings, listas, laços `for` e instruções `if`
- 17 lições com exemplos que você executa com um clique
- 36 perguntas de quiz, com combos e estrelas
- 25 desafios de código e 5 chefões, com correção automática e mensagens de erro em português
- XP, 10 níveis, bônus diário, sequência de dias e 14 conquistas
- Desafio Relâmpago: 60 segundos contra o relógio
- Laboratório livre para experimentar sem valer nota

### Duas versões
| | Onde fica | Como usar |
|---|---|---|
| **Site** (com login Google e ranking) | raiz do repositório | Publicado pelo GitHub Pages. Veja [COMO_PUBLICAR.md](COMO_PUBLICAR.md) |
| **App para Windows** (offline) | [`desktop/`](desktop/) | Rode `build_exe.bat` para gerar o `PyQuest.exe`, ou `Jogar_sem_exe.bat` |

## 🇺🇸 English

**PyQuest** turns your first steps in Python into a game. Read short lessons, run examples, answer quizzes and solve coding challenges that are graded instantly. At the end of each chapter, defeat a boss to unlock the next one.

### What's inside
- 5 chapters: getting started, variables and strings, lists, `for` loops and `if` statements
- 17 lessons with one-click runnable examples
- 36 quiz questions with combos and star ratings
- 25 coding challenges plus 5 boss fights, auto-graded with beginner-friendly error messages
- XP, 10 levels, daily bonus, streaks and 14 achievements
- Lightning Challenge: 60 seconds against the clock
- Free-play Lab to experiment without pressure

> The app content is currently in Brazilian Portuguese.

### Two versions
| | Location | How to use |
|---|---|---|
| **Website** (Google login + leaderboard) | repository root | Served by GitHub Pages. See [COMO_PUBLICAR.md](COMO_PUBLICAR.md) |
| **Windows app** (offline) | [`desktop/`](desktop/) | Run `build_exe.bat` to build `PyQuest.exe`, or `Jogar_sem_exe.bat` |
