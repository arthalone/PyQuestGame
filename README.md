# PyQuest 🐍

**🇧🇷 Aprenda Python jogando.** · **🇺🇸 Learn Python by playing.**

---

## 🇧🇷 Português

**PyQuest** transforma o início do aprendizado de Python num jogo. Você lê lições curtas, testa exemplos, responde quizzes e resolve desafios de código, que são corrigidos na hora. Ao final de cada capítulo, enfrenta um chefão para liberar o próximo.

### O que tem dentro
- 14 capítulos: primeiros passos, variáveis e strings, listas, laços `for`, `if`, dicionários, `input` e `while`, funções, classes, arquivos e exceções, testes e o projeto **Alien Invasion** (nave, frota de alienígenas, colisões, placar e recorde)
- 50 lições com exemplos que você executa com um clique
- 99 perguntas de quiz, com combos e estrelas
- 77 desafios de código e 14 chefões, com correção automática e mensagens de erro em português
- XP, 15 níveis, bônus diário, sequência de dias e 14 conquistas
- Desafio Relâmpago: 60 segundos contra o relógio
- Laboratório livre para experimentar sem valer nota
- Nos capítulos do Alien Invasion, um "pygame de treino" embutido (Rect, Sprite, Group, eventos), sem janela: você treina a lógica do jogo direto no navegador

### Duas versões
| | Onde fica | Como usar |
|---|---|---|
| **Site** (com login Google e ranking) | raiz do repositório | Publicado pelo GitHub Pages. Veja [COMO_PUBLICAR.md](COMO_PUBLICAR.md) |
| **App para Windows** (offline) | [`desktop/`](desktop/) | Rode `build_exe.bat` para gerar o `PyQuest.exe`, ou `Jogar_sem_exe.bat` |

## 🇺🇸 English

**PyQuest** turns your first steps in Python into a game. Read short lessons, run examples, answer quizzes and solve coding challenges that are graded instantly. At the end of each chapter, defeat a boss to unlock the next one.

### What's inside
- 14 chapters: getting started, variables and strings, lists, `for` loops, `if`, dictionaries, `input` and `while`, functions, classes, files and exceptions, testing, and the **Alien Invasion** project (ship, alien fleet, collisions, scoring and high score)
- 50 lessons with one-click runnable examples
- 99 quiz questions with combos and star ratings
- 77 coding challenges plus 14 boss fights, auto-graded with beginner-friendly error messages
- XP, 15 levels, daily bonus, streaks and 14 achievements
- Lightning Challenge: 60 seconds against the clock
- Free-play Lab to experiment without pressure

> The app content is currently in Brazilian Portuguese. The Alien Invasion chapters use a built-in "training pygame" (Rect, Sprite, Group, events) with no window, so the game logic runs right in the browser.

### Two versions
| | Location | How to use |
|---|---|---|
| **Website** (Google login + leaderboard) | repository root | Served by GitHub Pages. See [COMO_PUBLICAR.md](COMO_PUBLICAR.md) |
| **Windows app** (offline) | [`desktop/`](desktop/) | Run `build_exe.bat` to build `PyQuest.exe`, or `Jogar_sem_exe.bat` |
